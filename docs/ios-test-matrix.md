# iOS support and device test plan

Decision date: October 26, 2026. Status: minimum versions and test matrix selected; native execution pending.

## Minimum versions and build tools

Support iOS 16.4+ on iPhone and iPadOS 16.4+ on iPad. The deployment target is explicit in `apps/mobile/app.json:12`; tablet support remains at `apps/mobile/app.json:10`. This matches the installed Expo podspec's 16.4 floor and the [Expo SDK 58 requirements](https://docs.expo.dev/versions/v58.0.0/). Do not use React Native's lower standalone floor for this Expo app. Keep the same minimum on the future Share Extension target.

Expo SDK 58 requires Xcode 26.4 or newer. Select Xcode 26.4.1 as the initial reproducible local toolchain, on compatible macOS Tahoe 26.2 or newer within the supported 26.x range. Check the [Apple Xcode compatibility table](https://developer.apple.com/xcode/system-requirements/) before installing. A newer physical-device OS may require newer Xcode/device support; recheck the pairing when recording actual devices. The build SDK version and minimum supported device OS are different settings. Recheck App Store submission requirements before release.
